# Uploaded homepage photography — batch 1

These 18 original files were supplied by the owner in the conversation, not generated by the agent. Originals are kept unchanged for subsequent batches/reframing. `selection.json` records 17 selected images, display captions, desktop/mobile focal positions and a 90° counter-clockwise correction for the sideways wedding upload. The exhibition-stall image stays in the original intake ONLY: it is excluded from MAIN because that service was removed.

Optimized, metadata-stripped WebP copies are in `src/assets/homepage-real/`. No retouching, AI generation, upscaling, text/watermark removal or newly invented photography. Existing branding visible inside supplied photos is retained. Public image alt text is neutral inspiration, not a new assertion that Balloon Creation made every depicted installation.

Rebuild: install Pillow into `.cache/photo-tools`, then run `PYTHONPATH=.cache/photo-tools python3 scripts/prepare-homepage-photos.py` and `npx prettier --write src/lib/hero-slides.ts`. Future uploaded batches can be added to this intake/manifest without substituting generated imagery for missing occasions.
